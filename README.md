# Kanban Task Tracker

A responsive task-management application for creating tasks and organising them across different stages of a workflow.

This project is currently in development and is being built to strengthen my understanding of JavaScript, DOM manipulation and managing application data.

## Features

* Create tasks through a form
* Assign each task a status
* Display tasks as dynamically generated cards
* Automatically place tasks in the appropriate workflow column
* Organise tasks into Not Started, In Progress and Completed sections
* Responsive layout for different screen sizes

## Built With

* HTML5
* CSS3
* Vanilla JavaScript

## What I Practised

This project has helped me practise:

* Representing tasks as JavaScript objects
* Storing objects inside an array
* Rendering interface elements from application data
* Using conditional logic to determine where tasks should appear
* Handling form submissions and user input
* Creating and appending HTML elements with JavaScript
* Separating application data from the displayed interface
* Building responsive layouts with CSS

## Current Status

This project is still in development. The current version focuses on creating, rendering and organising tasks according to their workflow status.

Additional functionality will be added as my JavaScript skills develop.

## Running the Project Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No installation or external dependencies are required.
